# SWEEP — voice script (numbered lines for ElevenLabs)

How to use: paste each line into ElevenLabs separately, with the voice for its role. Download each take and **name the file by its number**: `01.mp3`, `02.mp3`, … `40.mp3`. Send them all to me; I place, cut, subtitle and mix them.
Text in *[brackets]* is a delivery note: don't paste it (or, with Eleven v3, paste it as an audio tag, e.g. `[whispers]`).

## Voices (cast)

| Role | Voice to choose | Settings |
|---|---|---|
| **N — Narrator** (the imp, older, remembering) | a warm, gentle male voice, slightly husky, unhurried; a storyteller, not an announcer | Stability ~50 %, Similarity ~75 %, Style ~20 %, speed 0.9 |
| **S — Sweep** (the imp, in the scene) | the **same voice** as N, a little higher and shyer (or pitch it up a touch) | Stability ~40 %, Style ~30 % |
| **K — the Great King** | a big, booming, gravelly male voice; pompous | Stability ~35 %, Style ~45 % |
| **C — the child** | a young child's voice (girl or boy), clear and small | Stability ~45 %, Style ~25 % |

## Act I — The Gate

| # | Role | Line |
|---|---|---|
| 01 | N | For three hundred years, I swept the gate of the Great King's cave. |
| 02 | N | Leaves in autumn. Snow in winter. Bones, mostly, the rest of the year. |
| 03 | N | The Great King had a hundred demons. A hundred names. |
| 04 | N | Iron Tusk. Seven Eyes. Mister Fang. |
| 05 | N | *[a small pause before it]* Nobody ever asked mine. |
| 06 | K | *[shouting]* You! Broom thing! Sweep faster! |
| 07 | N | *[dry]* I do not think he knew I had one. |
| 08 | N | Every morning, the demons marched down the mountain to frighten the villages. |
| 09 | N | Every evening, they marched back, and the gate was dirty again. |
| 10 | N | So I swept. That is what I was for. |
| 11 | N | *[softly]* Some nights, I swept the moon off the pond. |
| 12 | N | *[softly, smiling]* It always came back. I liked that about it. |

## Act II — The Storm

| # | Role | Line |
|---|---|---|
| 13 | N | Then came the summer of the great rain. |
| 14 | K | *[panicking]* The mountain is falling! Every demon for himself! |
| 15 | N | *[dry]* The Great King was the first to run. He is very brave, normally. |
| 16 | N | A hundred demons, gone in a hundred directions. |
| 17 | N | I stayed. Nobody had told me to stop sweeping. |
| 18 | N | *[quietly]* That was when I heard it. Crying, under the old pine. |
| 19 | C | *[tearful]* Is someone there? I can't find the path home. |
| 20 | N | A human child. Lost, and soaked, and smaller than my broom. |
| 21 | N | Demons are meant to frighten children. |
| 22 | N | I had never frightened anyone. I didn't know where to start. |
| 23 | C | *[small, scared]* Are you… a monster? |
| 24 | S | *[shy, after a beat]* I… sweep. |
| 25 | N | The water was rising. The path down the mountain was gone, under mud and broken trees. |
| 26 | N | *[slowly, decided]* So I did the only thing I know. |

*(Here the music stops. Silence. Then the great sweep — no voice.)*
